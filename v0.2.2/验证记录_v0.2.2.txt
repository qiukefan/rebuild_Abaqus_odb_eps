表面网格重建 v0.2.2 验证记录
日期：2026-10-11

本版范围
修复 Windows status.json 原子替换被短暂读句柄阻止的错误。
结果/缓存写入严格检查；运行中进度遇 Windows 占用时有限重试后可跳过。
完成/错误/取消状态独立发布 terminal.json，前端优先读取。
ODB 提取失败另留 extraction-error.json，避免进度冲突或启动器丢失 stderr 时丢掉原始错误。
本次没有修改变形倍率、配准、三维遮挡算法或增加支持的模型类别。

公开自动测试
Windows x64，完整包内 Python 3.12.14。
Python unittest 共 96 项：95 项通过，1 项私有几何数据验证按预期跳过。
Node 前端 mock 共 46 项通过。mock 不等于 Illustrator 真机操作。
新增覆盖：暂时文件锁重试，持续文件锁超时，旧 JSON 完整性，临时文件清理，
非锁 I/O 错误传播，进度冲突不影响数据输出，错误上报不掩盖原异常，
最终状态优先于旧进度，终态发布后进度副本失败不能反转成功。

真实 Windows 文件锁
使用 CreateFileW 打开已有进度文件，不启用 FILE_SHARE_DELETE。
复现旧的直接 os.replace 失败；另线程释放读句柄后，新版重试成功。
持续持锁时，新版在限定时间内失败，旧文件保持完整；仅进度发布可降级。
无需通过管理员身份或修改目录权限解决此类短暂共享冲突。

实际用户文件后台验证（私有文件不随发行包分发）
对报告错误的 case3 原始 EPS 使用对应 ODB，空模型/帧缓存启动。
Abaqus 2024 Python 3.10 通过 openOdb(readOnly=True) 读取，未运行求解器。
Step-2 / Step Time 200.0 / frame 1800 / Increment 2298。
从 EPS 识别变形倍率 X=1、Y=1、Z=10。
完成提取、配准、遮挡计算及新 EPS 输出，约 40.98 秒。
匹配 1437 个节点、6951 条原始网格描边；最大描边配准残差 0.000588007 pt。
输出 1879 条可见路径；生成结果报告和可复用模型模板。
测试中以 10 ms 间隔轮询进度文件。原 EPS SHA-256、ODB 大小和修改时间均未改变。
读取 ODB 和重建成功不等于所有遮挡逐边得到人工验证。
