表面网格重建 v0.2.1 验证记录
2026-10-10 / Windows / Abaqus Viewer 2024

本版修改
从 EPS 的 PostScript 文字读取统一或 X/Y/Z 分方向变形倍率。
统一使用 world = originalXYZ + [sx,sy,sz] * U，贯穿配准、三维遮挡和模板生成。
相机 JSON 同时保存 AUTO / UNIFORM / NONUNIFORM 及有效倍率供记录；重建以当前 EPS 标注为准。
旧 ODB 帧缓存中的原始坐标和位移可复用，不沿用旧显示倍率。
新版本有独立 JSX、后端和运行包；保留 v0.2.0，不覆盖已发布旧版。

公共自动测试
78 项 Python 测试：77 通过，1 项需要私有模型对照数据的测试按预期跳过。
42 项 Node 前端 mock 测试通过。
覆盖统一10倍、XYZ=[1,1,10]、科学计数法、负数与零、大小写、PS转义、DOS EPS载荷、忽略注释和预览。
缺轴、重复轴、逗号三元组、非有限数值、残缺或冲突标注明确拒绝，不截取首个数值作为倍率。
跨模块测试使用合成 C3D20，核对投影/遮挡前的真实三维坐标以及模板记录，避免只测试文字解析。
相机导出覆盖有效模式、取消、已有文件不覆盖、无 ODB、无效数值与失败写入清理。

真实 Abaqus EPS
通过独立的 Abaqus Viewer noGUI 进程，只读打开已有 Py60 ODB，Step-2 / frame1800 / Step Time=200.0。
使用已验证透视相机，导出统一1倍、统一10倍和X=1/Y=1/Z=10三张真正的Abaqus EPS及相机JSON。
原用户界面会话未修改；测试仅向独立验证目录输出文件，原 ODB 文件大小/修改时间不变，源 EPS 哈希不变。
EPS 实际标注格式与用户截图一致；导出的相机 JSON 有效倍率与 EPS 标注一致。

ODB模式（命中同一原始帧缓存）
统一1倍：1423个节点、6981条原网格黑线路径匹配，最大线条残差0.000542853 pt，约26秒。
统一10倍：1427个节点、7013条原网格黑线路径匹配，最大线条残差0.000573457 pt，约50秒。
X=1/Y=1/Z=10：1426个节点、7024条原网格黑线路径匹配，最大线条残差0.000537243 pt，约50秒。
三组均完整重建成功，倍率分别记录为[1,1,1]、[10,10,10]、[1,1,10]。
错误倍率对照：只在统一10倍EPS副本中把标注等长改成1倍，配准明确拒绝；未改原文件。
原图与结果的Ghostscript渲染对照中，轮廓、图例和文字位置一致；高密度网格在补全后会更黑。
原始网格线宽与叠加线宽同为0.56682453 pt，未额外加粗。
去除新增叠加内容并排除指定黑线paint-token替换后，三组EPS剩余PostScript与原文件逐字节一致，彩色绘图及注释未改写。
这些数据是本机和当前模型的实测，不是对所有模型或电脑的精度/速度承诺。

模板模式
统一1倍验证图生成的模板对同一EPS通过：恢复5078个节点、866个正面，正面内部重叠面积为0，彩色覆盖检查通过。
两组10倍变形图的模板复用检测到投影边界自交/折叠而拒绝；其ODB模式仍完整通过。
因此不承诺任意倍率变化都能免ODB；变化较大、遮挡复杂或模板校验拒绝时应使用当前ODB。
新版本允许读取v0.2.0模板格式，但当前EPS仍须重新通过全部几何校验；不能把该兼容性当作任意模板必定成功。

宿主与限制
v0.2.0已有Illustrator 29.6.1实机联调记录；本版新增测试针对倍率链路与真实Abaqus导出，不将mock视为新的Illustrator全流程验证。
仍仅支持已说明的原始Abaqus单视图EPS、单实例C3D20/C3D20R、U变形和可验证透视相机。
未增加任意相机反演、多实例、其他单元类型、坐标整体缩放或单元收缩功能。
真实ODB/EPS、缓存及测试图片均不随公开源码或运行包分发。
