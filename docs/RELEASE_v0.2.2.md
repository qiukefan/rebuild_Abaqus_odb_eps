# Surface Mesh Rebuild v0.2.2

本版修复 Windows 进度文件并发读写引发的 `PermissionError: [WinError 5] Access is denied`，继续支持 v0.2.1 的统一与 X/Y/Z 分方向变形倍率。

## 本版修复

- Illustrator 读取进度期间，后台原子替换 JSON 遇到短暂文件占用时有限重试，并清理临时文件。
- 普通进度更新暂时失败不再中断重建；进度显示可能短暂停在上一阶段。
- 通过独立任务终态文件交付完成、错误或取消状态，前端优先读取，避免因进度文件冲突丢失最终结果。
- 结果与缓存写入仍严格检查，持久写入错误不会被忽略或当作成功。

本次修复不改变网格配准和可见性算法，也不扩大现有单元、视角或模板复用范围。

## 验证

- 95 项 Python 测试及 46 项前端 mock 通过，1 项私有几何测试按预期跳过。
- 真实 Windows 文件锁已复现，释放后重试恢复通过。
- 用户报错的 case3 EPS 在空缓存下完成对应 ODB 读取和重建，约 41 秒，源文件未改动。本轮未重新验证 Illustrator 原生导入。

## 下载与升级

下载 **`SurfaceMeshRebuild-v0.2.2-windows-x64.zip`**，完整解压到新目录。GitHub 自动生成的 **Source code** 不含 Python 环境。

停止旧任务、关闭旧版脚本窗口后，在 Illustrator 打开由 Abaqus 直接导出的原始 EPS，运行 **`SurfaceMeshRebuild_v0.2.2.jsx`**，重新选择对应 ODB 并重建。保持 JSX 与 `v0.2.2` 文件夹的相对位置，不要与旧版后端混用。

**无需管理员权限，无需修改或重新计算 ODB。** 若旧版已报进度文件错误，直接用新版对原始 EPS 重试即可。结果仍在新文档打开，不覆盖原文件。

## 保留的功能与限制

- 自动读取 EPS 的 Step / Step Time 和变形倍率标注；统一倍率与 `x = 数值 y = 数值 z = 数值` 均支持，倍率以当前 EPS 为准。
- 需要 Windows 64 位、Illustrator；首次读取 ODB 需要兼容的 Abaqus。
- 支持原始 Abaqus 单视图矢量 EPS、单实例 C3D20 / C3D20R、U 变形及可验证的透视视角；不能处理任意 Illustrator 重保存 EPS。
- 同模型、同视角、小投影变化时可尝试免 ODB 模板；倍率变化较大、面重叠、折叠或证据不足时会拒绝，需使用对应 ODB。
- 云图、色标和文字保留；当前没有 GPU 后端。

完整包包含 Python 与几何依赖。原创代码采用 MIT，第三方组件保留各自许可证。实际验证及已知限制见 README 和本版验证记录。
